# Heart Disease Prediction Project ❤️

Machine learning project to predict heart disease and its severity level based on patient clinical data.

# Project Overview
Used the **Heart Disease UCI** dataset to build a predictive model. Handled data preprocessing, EDA, and model evaluation using **Random Forest** and **LightGBM**.

# Results
* **Best Models:** Random Forest & LightGBM
* **Accuracy:** 88.40% 
* **Target:** Predicts disease severity from `0` (normal) to `4` (severe).

# Tech Stack
* Python
* Pandas & NumPy
* Scikit-Learn & LightGBM

# Files
* `heart_disease_prediction.ipynb` - Jupyter notebook with full analysis & code.
* `heart_disease_uci.csv` - Dataset file.
